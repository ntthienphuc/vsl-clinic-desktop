# Legacy bank alias

This directory is retained as a local artifact from the earlier bank build. Its
`index.json` was built from the local `All_cam1` collection, not from official
QIPEDC dictionary videos, despite the historical directory name.

Use these provenance-first outputs for new work:

- `../qipedc-dictionary-index.json`: metadata index for the local export of the
  official QIPEDC dictionary, with QIPEDC source IDs kept separate.
- `../allcam1-bank/index.json`: candidate keypoint inventory for the local
  All_cam1 recognizer collection.

Do not copy IDs or promote motion from this legacy directory into the runtime
without signer, sense, and motion review.
